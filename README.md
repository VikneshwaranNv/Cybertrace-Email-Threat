# Cybertrace-Email-Threat
CyberTrace is an AI-powered DFIR platform that analyzes raw email headers (SPF/DKIM/DMARC), geolocates relay hops, and detects phishing and BEC threats using Gemini AI. It automatically maps attacks to the MITRE ATT&amp;CK framework and seals digital evidence into an immutable SHA-256 custody ledger for courtroom and SOC compliance.
